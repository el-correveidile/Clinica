# web-olimpo — landing de servicios para web.blablaele.com

Sitio estático que reemplaza al antiguo sitio de HubSpot en `web.blablaele.com`.

- `index.html` — landing única con todos los servicios de blablaELE
  (Aula Lingüístico-Cultural Olimpo de Estepona, clases online, clínica
  lingüística, talleres e inmersión cultural).
- `vercel.json` — redirección `/olimpo-estepona` → `/`.

Se despliega como proyecto independiente en Vercel (no forma parte del build
de Vite de la web principal, que vive en la raíz de este repo).
